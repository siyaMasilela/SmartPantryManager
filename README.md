\# Smart Pantry Manager



A Java Android application that suggests recipes based strictly on leftover ingredients to reduce food waste.



\## Features

\- 📦 Manage pantry items (add, edit, delete)

\- 📋 View all ingredients in a list

\- 🍳 Recipe collection with 15+ recipes

\- 🔍 Strict matching algorithm - only shows recipes you can make right now

\- ⚙️ Settings for expiry alerts and unit preferences



\## Database

This app uses \*\*SQLite\*\* for local data persistence with Room ORM.



\## Setup Instructions

1\. Clone the repository

2\. Open in Android Studio

3\. Sync Gradle

4\. Run on emulator or physical device



\## Technologies

\- Java

\- Android Studio

\- SQLite

\- RecyclerView
